Algorithm evaluation

How well do the three route-planning algorithms do? Each tries to visit as many customers as possible within the time limit, and to drive as little as possible while doing so.

How to read these results

A result is optimal when it makes the same number of visits as the exact solver and drives no more distance. The exact solver (branch and bound) checks every sensible route, so it is the reference for the best possible answer.

  • Nearest neighbour: always drives to the closest customer it can still reach. Quick, but can get trapped.
  • Greedy insertion: adds the customer that costs the least extra driving, one at a time.
  • Branch and bound (exact): finds the best route by search.
