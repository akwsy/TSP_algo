# T3: Averaged benchmark runner (after T1)
Scope: NEW `evaluation/src/evaluation/app/BenchmarkMain.java`, `evaluation/benchmark.sh`, `evaluation/tests/BenchmarkTest.java`, hook in `evaluation/test.sh`; output `evaluation/web/benchmark-data.json`.

Generate N seeded random scenarios per configuration from `submission/inputs/MY.txt` (vary customer count 5/8/10/12, window mode slack/blocks, period, start time), run nearest, greedy and exact on each, and report per configuration: mean, median and standard deviation of visits, share solved optimally (same visits as exact, no more distance), mean visits as % of exact, mean distance ratio, mean/max runtime. Flag configurations where exact hit its limit and exclude those from quality stats (count them). Deterministic for a given base seed; `--scenarios N --seed S --out file` options; default run takes under 2 minutes. JSON schema documented in a comment at the top of the class. Test: tiny run is deterministic, schema keys present, exact never worse than heuristics.
